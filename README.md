# โจทย์: พัฒนาโมเดล Speech-to-Text

พัฒนาโมเดล Speech-to-Text สำหรับถอดเสียงจากชุดข้อมูลที่กำหนดให้ โดยเลือกใช้โมเดลและวิธีการได้อย่างอิสระ (เช่น `whisper-large-v3-turbo`)

## สิ่งที่ได้รับ

1. ชุดข้อมูล (Dataset): โฟลเดอร์ [`dataset/`](dataset/) ไฟล์เสียง `.wav` จำนวน 1,305 ไฟล์ (16 kHz, mono)

## การนำเสนอ (Presentation)

จะมีการนัดวันเพื่อนำเสนอผลงาน ผู้ทำสามารถออกแบบและปรับแก้หัวข้อการนำเสนอได้ตามความเหมาะสม ตัวอย่างหัวข้อ:

### 1. วิธีการจัดการ Data
ขั้นตอนการทำ Data Cleaning, Preprocessing หรือ Augmentation

### 2. วิธีการ Fine-tune
สถาปัตยกรรมโมเดลที่เลือกใช้ และกระบวนการ Fine-tuning

### 3. วิธีการเปรียบเทียบผลลัพธ์
ขั้นตอน เงื่อนไขการทดสอบ และตัววัดผลที่ใช้เปรียบเทียบประสิทธิภาพก่อนและหลัง Fine-tune

## Tips

- ไฟล์เสียงมีจำนวนมาก การนั่ง label ทีละไฟล์ด้วยมืออาจใช้เวลานาน หากมีวิธีที่มีประสิทธิภาพกว่าในการ label ก็สามารถใช้ได้เลย
- ความยาวเสียงรวมประมาณ 43 นาที ลองคิดดูว่าจะใช้ข้อมูลยังไง
